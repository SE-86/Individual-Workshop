# 单独工坊

单独工坊是从万联社区「更多工坊」中挑选部分页面整理而成的 HTML 功能合集分支版本。所有页面均为纯静态 HTML 文件，下载后双击即可使用，无需安装任何软件、无需搭建服务器。

## 与更多工坊的关系

本项目衍生于万联社区的「更多工坊」，仅保留了其中部分页面，并整理成独立版本，方便直接下载使用。分支版本统称为「单独工坊」。

## 功能目录

> 🚧 内容建设中。页面正在陆续整理汇入，完成后会在此处按类别列出，格式为「`文件名.html` —— 用途」。
>
> 计划收录的方向：工具类、娱乐类、信息类等，具体页面以实际文件为准。

## 快速开始

1. 点击仓库右上角 **Code** 按钮，选择 **Download ZIP** 下载整个仓库；
2. 解压下载的压缩包，进入文件夹；
3. 双击任意 HTML 文件，即可在浏览器中打开使用。

无需安装环境、无需启动服务器。页面内如有引用外部资源，对应功能可能需要联网。

## 添加新功能

如果你想往合集中加入新的页面：

1. 将 HTML 文件放入对应分类的目录；
2. 文件命名建议使用「中文名.html」，方便识别；
3. 在主页索引中登记该页面，便于统一入口访问。

## 常见问题

- **页面打开后是空白？**
  请确认文件已完整下载（尤其是用 ZIP 下载时需先解压），并尝试使用较新版本的浏览器打开。
- **可以修改这些页面吗？**
  可以。本项目为整理分享性质，欢迎自行修改使用。
